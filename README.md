# PHP Tasks

This repository contains PHP practice tasks completed during my Full-Stack Web Development training at **Orange Coding Academy — Cohort 7**.

## Technologies Used

- PHP
- HTML5
- CSS3
- XAMPP (Apache)
- Git & GitHub

## Tasks

### 1. Cookies, Sessions, GET & POST
Practice working with PHP cookies, sessions, and HTTP request methods.

### 2. Form Validation
Practice handling and validating user input using PHP.

### 3. PHP Session Login
Practice building a basic login system using PHP sessions.

### 4. PHP Superglobals
Practice using PHP superglobal variables to handle requests and user data.

## How to Run

1. Install XAMPP.
2. Clone this repository into `C:\xampp\htdocs`.
3. Start Apache from the XAMPP Control Panel.
4. Open `http://localhost/PHP-Tasks/` and navigate to the desired task folder.

## Learning Objectives

- Understand server-side programming with PHP.
- Work with HTML forms.
- Handle GET and POST requests.
- Validate user input.
- Understand cookies and sessions.
- Practice basic login functionality.
